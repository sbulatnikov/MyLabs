MyLabs — исходники сборки (версия 0.9.0, бета)
====================================================
Аддон для Аллодов Онлайн: личный лабиринт по всем персонажам аккаунта — рога изобилия,
ресурсы лабиринта, сундучок хранителя, расчёт нового рога.

lua/       скрипты в UTF-8 (при сборке переводятся в Windows-1251, концы строк CRLF)
             LibDnD.lua  перетаскивание окна и кнопки (чужая библиотека, уже в Windows-1251)
             Util.lua    строки, журнал, время, обёртки над виджетами
             Core.lua    данные, рога, валюты, сундучок, автоматика — без интерфейса
             UI.lua      кнопка, окно, выпадающий список
             Main.lua    запуск, события, реакции, команды чата
gen/       генератор ресурсов (Python 3 + numpy + Pillow + rsvg-convert)
             build.py    виджеты, тексты, текстуры DXT5
             assemble.py папка аддона целиком + проверка ссылок и имён виджетов
             pak.py      собранная папка аддона -> MyLabs.pak (ZIP с путями Mods/Addons/MyLabs/...)
             tree.py     дерево виджетов в таблицу Lua — для проверки скриптов
             render.py   грубый предпросмотр окна в PNG
             tex.py, xdb.py — общие с BestAutoAccept
assets/    картинки из ресурсов игры (значки ресурсов, фракций, рога, сундучка)
test/      прогон на заглушках API игры: sh test/run.sh
promo/     карточки для форума (PNG 1600x900): python3 promo/cards.py <папка>, нужен google-chrome
observer-0.1.5/  прежний аддон-наблюдатель (писал разговоры с рогами в mods.txt) — оставлен как инструмент отладки

Сборка:    python3 gen/assemble.py <папка>        ->  <папка>/MyLabs
Проверка:  sh test/run.sh <папка>                 (нужен texlua; скрипты проверяются в Windows-1251, как в игре)

Где что хранится
----------------
Общая секция настроек "MyLabsData" (одна на все персонажи аккаунта):
  db.chars[ключ] = { name, shard, fac, res = {granite, coral, embrium, meteor, supplies, mercs}, resAt,
                     horns = { [строка] = { st = busy|free|done, prod, amount, per (дней), seen (когда видели),
                                            assign (что назначено | "none"), x, y, n (точка разговора) } },
                     hornCount, cost (цена следующего рога), costFor, chest (что брать из сундучка), menu, vol }
  db.order — порядок персонажей, db.auto — автоматика включена.
Секция "MyLabs" занята LibDnD (положение окна и кнопки) — свои данные туда не писать.

Как рог попадает в свою строку
------------------------------
Игра не отдаёт ни постоянного номера рога, ни его позиции; id объекта меняется при каждом входе в зону.
Внутри посещения рог привязан к строке по id. При новом посещении строка подбирается один-к-одному:
сначала по состоянию (что добывает, сколько дней осталось), затем по близости точки, с которой
персонаж разговаривал с рогом. Соседние рога с одинаковым состоянием могут поменяться строками —
на то, что будет запущено, это не влияет.

Команды чата
------------
/mylabs            открыть или закрыть окно
/mylabs auto off   выключить автоматику (сбор, запуск, сундучки); auto on — включить
/mylabs reset      забыть рога текущего персонажа
/mylabs debug      подробный журнал шагов автоматики в Personal\Logs\mods.txt
