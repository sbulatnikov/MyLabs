# MyLabs

Аддон для «Аллодов Онлайн»: личный лабиринт на всех персонажах аккаунта — рога изобилия, ресурсы лабиринта
и сундучок хранителя. Замена LabCalendar.

![Окно MyLabs](release/promo/MyLabs-1-cover.png)

Версия 0.9.3 (бета). Автор — NoMercy.

## Что умеет

- **Рога изобилия.** У каждого рога видно, что запущено, что назначено и сколько дней осталось. Когда вы заговорили
  с рогом, аддон сам забирает готовую добычу и запускает назначенное. Назначать можно любому персонажу, не заходя им в игру.
- **Все персонажи аккаунта.** Слева — список персонажей: сколько рогов готово или простаивает, через сколько дней
  будет готов ближайший. В карточке персонажа — шесть ресурсов лабиринта.
- **Сундучок хранителя.** Для каждого персонажа выбирается, что брать: золото, слезу дракона, коралл или гранит.
  Аддон открывает все сундучки в сумке сразу.
- **Новый рог.** Цена следующего рога, сколько коралла не хватает и сколько эмбриума уйдёт на обмен.

Полное описание — [release/description.html](release/description.html), список изменений —
[release/changes.md](release/changes.md).

## Установка

1. Скачайте `MyLabs.pak` со страницы [Releases](../../releases).
2. Положите файл в `<папка игры>\data\Mods\Addons\`. При обновлении новый файл заменяет прежний.
3. Выключите LabCalendar: оба аддона выбирают ответы в разговоре с рогом и будут мешать друг другу.

## С чего начать

1. Зайдите персонажем в личный аллод и заговорите с каждым рогом изобилия — в окне появятся строки.
   Аддон узнаёт о роге только из разговора с ним.
2. Поговорите с прорабом — появится цена следующего рога.
3. Повторите на остальных персонажах. Данные общие для всего аккаунта.

## Команды чата

| Команда | Что делает |
| --- | --- |
| `/mylabs` | открыть или закрыть окно |
| `/mylabs auto off` | выключить автоматику: аддон только записывает; `auto on` — включить обратно |
| `/mylabs reset` | забыть рога текущего персонажа (строки соберутся заново из разговоров) |

## Ограничения

- Игра не даёт аддонам ни номера рога, ни его координат. Строка таблицы — это место, а не конкретный рог:
  соседние рога с одинаковой добычей и сроком могут поменяться строками. На то, что будет запущено, это не влияет.
- Срок до готовности точен до суток. «Готов» до разговора с рогом — это расчёт.
- Курс обмена «1 эмбриум за 5 коралла» взят из LabCalendar, в игре не проверен.
- Рога и сундучок узнаются по названиям в русском клиенте.
- Окно 989 × 811 точек: рассчитано на экран от 1080 по высоте.
- Два окна игры одновременно не поддерживаются.

# Разработчикам

```
lua/       скрипты в UTF-8 (при сборке переводятся в Windows-1251)
gen/       генератор: assemble.py собирает папку аддона, pak.py — MyLabs.pak
tools/     strip_debug.py — вырезает отладку из скриптов при сборке
assets/    значки и шрифт
test/      прогон скриптов на заглушках API игры
release/   описание, список изменений и карточки текущего выпуска
```

## Сборка

Нужны Python 3 с `numpy` и `Pillow` и `rsvg-convert` (пакет `librsvg2-bin` в Debian и Ubuntu).

```
python3 gen/assemble.py out                  ->  out/MyLabs — папка аддона
python3 gen/pak.py out/MyLabs out/MyLabs.pak ->  файл для data\Mods\Addons
```

Версия задаётся в одном месте — `ML.VERSION` в `lua/Util.lua`. Отладочная сборка — с переменной `ALLODS_DEBUG=1`.

## Тесты

```
sh test/run.sh                    обычная сборка
ALLODS_DEBUG=1 sh test/run.sh     отладочная сборка
```

Кроме сборки, нужны `iconv` и `texlua` или `luajit` (свой интерпретатор — `LUA=<путь>`). Те же проверки запускаются
в GitHub Actions на каждый pull request.

## Ветки и выпуски

`main` — только выпущенное. Доработка — в ветке `feature/<коротко>` или `fix/<коротко>` и через pull request.
Выпуск — слияние в `main` и тег `v<версия>`: по тегу GitHub Actions сам собирает `MyLabs.pak` и создаёт выпуск
с описанием из `release/changes.md`.
