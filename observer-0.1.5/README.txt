MyLabs — исходники
==================
lua/    скрипты аддона в UTF-8 (в папке аддона они в Windows-1251)
test/   заглушки API и прогон: texlua test/run.lua lua

Версия 0.1.5 — наблюдатель. В игре ничего не нажимает и не выбирает.
Пишет в Personal\Logs\mods.txt строки с меткой [MyLabs]:
  - при входе персонажем: аккаунт, персонаж, сервер, фракция, время, зона, эффекты, все валюты, предметы сумки с выбором действия;
  - при каждом разговоре (EVENT_INTERACTION_STARTED): собеседник, позиции, реплика и все ответы с псевдонимами данных;
  - для рога изобилия: сравнение с прежними встречами (id объекта и расстояние) и запись в общую секцию настроек MyLabs;
  - изменения валют, новые предметы в сумке, смена зоны.
Команды чата: /mylabs, /mylabs dump, /mylabs mark текст.
